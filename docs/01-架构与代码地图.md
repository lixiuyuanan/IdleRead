# 01 · 架构与代码地图

对应版本 1.7.3.2（`app.js` 8,498 行）。行号会随版本漂移，找代码以 `/* ---------------- 区块名 ---------------- */` 为准。

---

## 一、总体结构

```
Android WebView
└── assets/www/index.html        固定骨架
    ├── #topbar                  返回 / 标题 / 朗读 / 收藏 / 更多
    ├── #levelStrip              难度条（在 #view 之外，切页不重排）
    ├── #view                    唯一的内容容器，整页替换 innerHTML
    ├── #contPill                「接着读」浮条
    └── #tabbar                  阅读 / 复习 / 我的

app.js（IIFE）
├── 常量与运行时状态
├── 纯函数层：分词、词形、词典、词性、分档、SRS、格式化
├── 数据层：localStorage 存档、IndexedDB 本地书、收藏/历史/划线
├── 服务层：DeepSeek、腾讯翻译、更新检查、镜像、下载
├── 视图层：renderXxx() 生成字符串 → innerHTML；事件统一委托
└── 原生桥：window.Android.*
```

设计取舍：

- **无框架**。设备上的 WebView 版本不可控，引入构建链只会增加“本地能跑、手机白屏”的风险。ES5 是硬约束。
- **整页替换 + 委托事件**。每个页面由 `renderXxx()` 返回 HTML 字符串，`#view.innerHTML = html`，事件都挂在 `document` 上按 `data-*` 分派。代价是不能用组件状态，收益是没有 diff 开销、没有内存里的旧 DOM。
- **难度条在 `#view` 外**。切档时 `#view` 整块重画，但难度条只改选中类，不重排，所以不会闪。
- **重活给原生**。TTS、下载、安装、文件选择、剪贴板、主题色都不在 JS 里做。

## 二、启动流程

1. `index.html` 只有骨架，`#boot` 显示“正在装书…”。
2. `app.js` 立即执行：读 `localStorage['ldleRead.mobile.v1']` → `normalizeStore()` 补齐/清洗字段。
3. `fetch('data/articles.json')` + `data/dict.json` + `data/lemma.json`。
4. 建索引（文章按档、词头缓存、复习池），渲染首页列表，移除 `#boot`。
5. 原生 `onReady()` 回调后才允许 TTS 等桥能力；冷启动若 `resume_stem` 有效，直接进阅读页并恢复滚动位置。

数据文件缺任何一个，启动会停在 boot 页 —— 本仓库不包含数据，原因见根 README。

### `articles.json` 的字段

```js
{ "articles": [ {
  s: "3-13",        // stem，唯一键
  l: 3,             // level：1 小学 2 中考 3 高中 4 四级 5 六级 6 考研一 7 考研二 90 书架
  q: 42,            // seq，原始顺序；永不重排
  t: "标题",         // 标题
  w: 512,           // 词数
  p: ["英文段1", …],// 段落数组，与 c 一一对应
  c: ["中文段1", …],// 译文；段数不等时整篇不显示译文
  k: true,          // pair_ok：英文与译文段数一致
  tp: 3,            // 主题标签 1~6
  e: 1,             // 是否真题
  b: "book-1", bt: "书名", cn: 3,  // 书架章节才有
  o: 12             // 书架内的排序
} ] }
```

### `dict.json` / `lemma.json`

```js
dict["abandon"] = ["ə'bændən", "vt. 放弃，抛弃", 1203, "zk gk cet4"];
lemma["abandoned"] = "abandon";
```

`rank` 是通用词频排名（0 表示未知），`tags` 是空格分隔的考试标签。算法细节见 `03-词典与难度算法.md`。

## 三、存档结构（localStorage）

键：`ldleRead.mobile.v1`。整体是一个对象 `S`：

| 字段 | 内容 |
|---|---|
| `settings` | 字号、主题、学习目标、朗读语速/音高、翻译源、更新频率、浮条开关与位置、`onboarded` 等 |
| `articles[stem]` | `{ read:[段号], done:bool, done_at, times:次数 }` |
| `words[word]` | 生词本记录 + SRS：`{ st:阶段, stab:稳定度, due, last, chk, pass, n }` |
| `marks[]` | 划线/笔记：`{ i:stem, s:句文本, p:段号, r:[[起,止]…], n:笔记, t:时间, a/b:扩展边界 }` |
| `favorites` | `{ folders:[{id,name}], map:{文章stem→folderId} }` |
| `history[]` | 最近阅读，最多 200 |
| `days{}` | 每日阅读词数，用于统计 |
| `read_words{}` | 每篇已读词集合，用于进度 |
| `readPos{}` | 每篇退出位置，最多 300 篇 |
| `hidden_books{}` | 隐藏的书架书 |
| `recent[]` | 最近搜索/操作 |

约定：

- 新增设置键**必须**同时加进 `DEFAULT_SETTINGS`，否则刷新后被 `normalizeStore()` 丢弃。
- `bare(obj)` 把 JSON 对象换成无原型对象，防止 `constructor` / `__proto__` 当键。
- `save()` 180ms 防抖，`saveNow()` 立即落盘；一次性引导等场景用后者。

## 六、性能与兼容约定

- **只动 `transform` / `opacity`**：转场、跟手、卡片动画都不碰布局属性。
- **长列表用 `content-visibility`**：581 篇的书架列表只渲染视口附近。
- **重解析结果进缓存**：`knownCache` / `hiCache` / `hintCache`，语料或设置变化时 `dropCaches()` 统一失效。
- **缓存版本号**：字体/主题切换不解绑事件，靠 `cachesRev` 让依赖缓存重建。
- **禁止在 touchmove 里读布局**：跟手路径只读启动时快照 + 位移。
- **ES5**：不用 `let/const`、箭头函数、模板字符串、`Object.assign`；`apk_check.py` 会扫违规。
- **HTML 字符串一律 `esc()`**：标题、释义、用户输入都过转义，再拼进 `innerHTML`。
