# 闲读 IdleRead

**读得更多，也读得更久。**

一个把查词、朗读、复习、笔记放在同一本书里的英文阅读器。
不背单词表，靠读闲书把词记住。

---

## 为什么要做这个东西

背单词表有三道过不去的坎。

**任意符号难题。** 一个单词和它指的东西之间没有必然联系——"apple" 为什么是苹果？没有道理，只能硬记。
而纯靠背单词建立起来的记忆，脆弱、孤立、一碰就忘。

**宽度难题。** 单词知识像海洋一样宽。一个词有搭配、有语域、有褒贬、有常见与罕见用法。
单词表只能给你一条中文释义，就像用木桶去舀海。

**深度难题。** 单词知识又像井一样深。知道 "run" 是"跑"，和知道 "run a company""the engine runs""a run in her stocking"，
完全不是一回事。背单词只触及水面。

## 语境才是解药

词汇是丝线，文本是织品。只有在语境里，一个词才有生命——
它跟谁搭配、在什么场合出现、带着什么情绪。图像、声音、事件、情感会把它钉进记忆里。

语言学界把这条路叫 **可理解输入**：如果每读一百个词，只遇到两三个生词，你就能像拼拼图一样，
从上下文里把生词的意思推出来。而且——**一个词往往要在不断变化的语境里遇到十几次，才算真的学会**。

纯背单词做不到"不断变化的语境"，只有阅读能。有位匈牙利翻译家 Lomb Kato 掌握十五门外语，
她的方法简单到不像方法：**读原著闲书**。她自己说过，只有阅读才能带来那种无限的重复。

## 一百万词

有人统计过 Sidney Sheldon 的十本小说，总篇幅约一百万词。这一百万词，
对大学英语六级的词汇覆盖率超过 90%，平均每个词重复 26 次。

也就是说：**读完一百万词的闲书，六级词汇几乎就自己长出来了。**

每天读半小时，一年正好是一百万词。但习惯不能一口吃成——先从每天读半页纸开始。

闲读就是为这条路做的工具：**把"读闲书"变得足够省力，让你真的读得下去。**

---

## 闲读怎么帮你读完这一百万词

**按难度分好档，生词率可控。**
中考、高中、四级、六级、考研一、考研二六档，每篇文章按词汇覆盖率定档——
目标就是让你每读一百个词只碰上两三个生词，正好够推、又不至于读不下去。

**点一下就查，不离开这一页。**
点任意单词，出音标、发音和中文；还会结合这一句判断词性，只高亮对得上的那条释义。
不需要跳出阅读去翻词典，读的节奏不会断。

**点句子就朗读，耳朵也算一遍。**
读累了可以听；正在读的句子整句变色，跟着走不会丢。

**译文就在手边。**
真题文章都配了整篇中文，看不懂的段落点右上角「译」对照一眼，不用猜到底。

**生词自己攒，复习自己排。**
点过的词自动进生词本，复习页按到期时间排队，一张卡一个词，配着**你当时读到的那句原文**——
重复发生在语境里，而不是在单词表里。

**整本书也能读。**
书架里放了 29 本原著（神奇树屋、彼得潘、绿野仙踪、伊索寓言……），按书分章，读完一章记一章。

**自己的书也能进来。**
手上有 TXT 就导入，App 会按章节切分并配翻译。

**读了多少，一眼看得见。**
统计页记今日词数、达标天数、连续天数、近 7 天和累计——把"每天半页"这件事变成看得见的进度条。

## 下载与更新

- 项目主页：https://github.com/lixiuyuanan/IdleRead
- 发布页：[Releases](../../releases)，下载 `IdleRead-版本号.apk`
- 国内镜像（第三方加速源，打不开 GitHub 时用）：把下载链接开头的 `https://github.com` 换成
  `https://gh-proxy.org/https://github.com`、`https://gh.ddlc.top/https://github.com`
  或 `https://gh-proxy.com/https://github.com`

安装时如果提示「未知来源」，允许本次安装即可。升级直接覆盖安装，**不要先卸载**——卸载会清掉本地数据。

App 内「我的 → 设置 → 软件更新与发布地址」可以检查新版本并直接下载安装包。自动检查默认「登录时」一次，
可改成三天 / 七天 / 永不。下载页显示进度条，**下完自动比对 SHA-256**：一致时进度条变绿、出现「安装」按钮；
不一致会先用单一源重下一遍，仍不一致才删掉并提示换源。第一次安装会要求允许「安装未知应用」，允许后返回会自动续装。

下载采用 **测速选源 + 多源并发**：先对候选镜像各拉一小段测速，挑最快的几条同时下，把文件切块丢进队列，
哪个源快就多干。镜像不支持分块会自动退回单连接。**下载中可以暂停，「继续」接着下**，不用从 0 重来。

### 下载镜像源

「我的 → 设置 → 下载镜像源」可以看到当前在用的清单，点「同步」拉远端维护的最新版本。
**同步是合并不是替换**：远端测过的排前面，内置的不重名就继续留着。拉不到就继续用现有的。
远端清单更新后，进「软件更新与发布地址」会自动比对，**过期时页面顶部提示「当前下载源已过时」，点「更新」一键同步**。

镜像都是第三方加速服务，只负责搬运文件；装之前一定会核对 SHA-256，对不上不会装。

## 系统要求

- **Android 7.0（API 24）及以上**，低于这个装不上
- 系统 WebView 建议 **Chromium 84 以上**（2020 年后的版本）。界面依赖新的 CSS 排版，WebView 太旧会出现间距挤在一起
- 内存 1 GB 起，建议 2 GB；可用存储建议 ≥100 MB（含导入的书和下载的更新包）
- 语音朗读需要一个系统 TTS 引擎（Google 文字转语音或厂商自带）；没有也能正常阅读，只是没有声音
- 阅读本身完全离线；只有检查更新、下载安装包时才需要联网

## 第一次使用

1. 打开后先选难度：中考、高中、四级、六级、考研一、考研二，或者书架里的整本书。
2. 点一篇文章开始读；退出会记住读到哪里。
3. 底部四个入口：阅读、复习、统计、我的。

## 阅读时

- **点单词**：出发音、音标和中文；结合这句话判断词性，只高亮对应的那条释义。
- **点句子**：朗读这一句（需要手机装好语音引擎）；正在读的句子整句变色。
- **长按单词或选区**：弹出「选中全句 / 复制 / 翻译 / 划线」；选中后可以拖动两端的手柄，扩大到一个短语。
- **划线**：选中后点「✎划线」，文字变黄色高亮；同一句再划线会并入同一条。
- **长按已划线的文字**：可以取消划线、记笔记或翻译。
- **词典没收录的词**：卡片上会显示红字「该词汇未收录，点我翻译」；有释义但觉得不对，可以点「重译」。
- **底部标签可以连续滑**：在阅读页里按分类一路滑过去，滑完一个难度自动进下一档；最后一个难度滑完直接进复习页。

## 生词与复习

- 点过的词会自动进生词本，不需要手动收藏。
- 「复习」里先看到今天到期的词，默认「不会优先」；点开始，一张卡一个词。
- 每张卡带一条你当时读到的原句；点绿「认识」或红「不认识」，判断后才显示中文和词义。
- 点「认识」后如果发现记错了，点「记错了」可以撤回，也可以直接进入下一词。
- 想深挖一个词，去「语境复习」：输入词查看 15 条原句，可逐句翻译、跳回原文；挖空模式下不显示翻译。

## 收藏与笔记

- 收藏页分「文章」和「划线」两栏。
- 划线的句子会生成卡片：黄色原句、可编辑笔记（自动保存）、「翻译」「查看原文」「删除」。
- 点「查看原文」会跳到文章里的那句话，并高亮几秒。

## 统计与记录

- 统计页记录：今日读了多少词、目标进度、达标天数、连续天数、近 7 天和累计数据。
- 读过的篇章进度、查过的词都会自动留下记录。

## 导入与备份

- 阅读页右上角「＋」→「导入图书」可以导入 TXT；导入的书会自动配翻译。
- **导入规则**：右上角「＋」→「复制导入规则（必看！）」会把 App 支持的编码、章节标题写法和分段规则复制到剪贴板；
  粘给 AI，让它按规则生成 .txt，导入成功率最高。
- 换手机或重装前，在「我的」里先「导出存档」，新手机再导入，阅读记录、生词、收藏、划线都能恢复。
- 所有数据只存在本机，不用注册；AI Key 不会写进导出的存档。

## 语音设置

- 「我的 → 设置 → 语音朗读」可以调语速、音高，也可以重启语音引擎。
- 页面底部有 **Google 语音引擎** 卡片，按包名 `com.google.android.tts` 自动判断状态：
  - **没装**：给两个入口——「镜像下载安装（约 36 MB）」不需要 Play 商店，下完自动校验、自动装好；
    「从 Google 商店安装」会**直接打开 Google Play**，没装 Play 的机器会提示改用镜像下载。
  - **装了但没选中**：给「去系统语音设置」，把首选引擎改成「Google 语音识别和语音合成」。
  - **已启用**：显示「已启用」，不再打扰。
- 镜像下的是**合并好的完整单包**（不是分体 `.apks`）：小米 / MIUI 上不用关闭「MIUI 优化」，和普通 App 一样安装即可。
  这个包用闲读自己的密钥重签过，**不要再用 Google 商店更新它**（会签名冲突），换版本回到这张卡片重新下载。
- 这个引擎包要求 **Android 12L 及以上**（Google 官方限制），系统版本低会直接提示，不会白下 36 MB。
- 语音设置里的「重启」会真正重启 App，并回到语音设置页。

## 常见问题

- **翻译显示「稍后再试」**：翻译接口临时限流，过一会儿再点，不会自动反复重试。
- **没有声音**：检查系统语音引擎和媒体音量；换一个 TTS 引擎再试。
- **词性没标**：规则判断拿不准时会主动不标，避免误导；可以看单词卡里的全部释义。
- **新版本怎么更新**：在「我的 → 设置 → 软件更新与发布地址」里检查并直接下载，或到发布页下载新 APK 覆盖安装；不要卸载。
- **下载很慢**：镜像速度跟网络关系很大，App 每次下载前都会重新测速挑最快的几条。也可以在「设置 → 下载镜像源」点一次同步，
  或换个网络（流量 / 换 Wi-Fi）再试。
- **下载中断了**：点「继续」会从断点接着下。为了避免中断，下载时尽量别切走或熄屏。
- **换签名会怎样**：签名变了就不能覆盖安装，只能卸载重装，记得先导出存档。

## 隐私

不登录、不上传阅读记录，离线也能读；只有查词、翻译时才联网。
