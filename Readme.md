# 闲读 IdleRead

**读得更多，也读得更久。**

一个把查词、朗读、复习、笔记放在同一本书里的英文阅读器。

## 下载与更新

- 项目主页：https://github.com/lixiuyuanan/IdleRead
- 发布页：下载：[Releases](../../releases) （下载 `IdleRead-版本号.apk`）
- 国内镜像（非官方加速源，打不开时用）：把下载链接开头的 `https://github.com` 换成
  `https://gh-proxy.org/https://github.com` 或 `https://gh-proxy.com/https://github.com`。

安装时如果提示「未知来源」，允许本次安装即可。新版本直接覆盖安装，不要先卸载。

App 内「我的 → 设置 → 软件更新与发布地址」可以检查新版本，并直接下载安装包。自动检查默认是「登录时」查一次，可在同一页改成三天 / 七天 / 永不。安装包旁边会贴着 GitHub 给的 SHA-256 哈希；下载时页面显示进度条，**下完 App 自动比对哈希：一致时进度条变绿、右侧出现「安装」按钮，点一下就装；不一致会先用单一源重下一遍，仍不一致才删掉并提示换源**。第一次安装会要求允许「安装未知应用」，允许后返回 App 会自动继续装。

下载采用 **测速选源 + 多源并发**：点下载后先对所有候选镜像各拉一小段测速，挑最快的几条同时下，把文件切成小分块丢进任务队列，哪个源快就多干、慢的自动少干；单个镜像被限速时总速度还能叠起来。镜像不支持分块会自动退回单连接。

**下载中可以暂停，点「继续」接着下**，已下载的部分会保留，不用从 0 重来。下载时页面会提示「请勿退出 App」——切走或熄屏可能让系统回收进程，下载就断了。

### 下载镜像源

「我的 → 设置 → 下载镜像源」可以看到当前在用的镜像清单，点「同步」拉一次远端维护的最新清单。**同步是合并不是替换**：远端测过的排前面，内置的只要不重名就继续留着，所以同步不会让候选变少。拉不到就继续用现在这份，不影响使用。

镜像都是第三方加速服务，只负责搬运文件；装之前一定会核对 SHA-256，对不上不会装。

## 第一次使用

1. 打开后先选难度：中考、高中、四级、六级、考研一、考研二，或书架里的整本书。
2. 点一篇文章开始读；退出会记住读到哪里。
3. 底部四个入口：阅读、复习、统计、我的。

## 阅读时

- **点单词**：出发音、音标和中文；会结合这句话判断词性，只高亮对应的那条释义。
- **点句子**：朗读这一句（需要手机装好语音引擎）；正在读的句子整句变色。
- **长按单词或选区**：弹出「选中全句 / 复制 / 翻译 / 划线」；选中后可以拖动两端的手柄，扩大到一个短语。
- **划线**：选中后点「✎划线」，文字变黄色高亮；同一句再划线会并入同一条。
- **长按已划线的文字**：可以取消划线、记笔记或翻译。
- **词典没收录的词**：卡片上会显示红字「该词汇未收录，点我翻译」；有释义但觉得不对，可以点「重译」。

## 生词与复习

- 点过的词会自动进生词本，不需要手动收藏。
- 「复习」里先看到今天到期的词，默认「不会优先」；点开始，一张卡一个词。
- 每张卡带一条你当时读到的原句；点绿「认识」或红「不认识」，判断后才显示中文和词义。
- 点「认识」后如果发现记错了，点「记错了」可以撤回。
- 想深挖一个词，去「语境复习」：输入词查看 15 条原句，可逐句翻译、跳回原文；挖空模式下不显示翻译。

## 收藏与笔记

- 收藏页分「文章」和「划线」两栏。
- 划线的句子会生成卡片：黄色原句、可编辑笔记（自动保存）、「翻译」「查看原文」「删除」。
- 点「查看原文」会跳到文章里的那句话，并高亮几秒。

## 统计与记录

- 统计页会记录：今日读了多少词、目标进度、达标天数、连续天数、近 7 天和累计数据。
- 读过的篇章进度、查过的词都会自动留下记录。

## 导入与备份

- 阅读页右上角「＋」→「导入图书」可以导入 TXT；导入的书会自动配翻译。
- **导入规则**：右上角「＋」→「复制导入规则（必看！）」会把 App 实际支持的编码、章节标题写法和分段规则复制到剪贴板；粘给 AI，让它按规则生成 .txt，导入成功率最高。
- 换手机或重装前，在「我的」里先「导出存档」，新手机再导入，阅读记录、生词、收藏、划线都能恢复。
- 所有数据只存在本机，不用注册；AI Key 不会写进导出的存档。

## 语音设置

- 「我的 → 设置 → 语音朗读」里可以调语速、音高，也可以重启语音引擎。
- 页面底部有一张 **Google 语音引擎** 卡片，靠包名 `com.google.android.tts` 自动判断状态：
  - **没装**：给两个入口——「镜像下载安装（约 36 MB）」不需要 Play 商店，下完自动校验、自动装好；
    「从 Google 商店安装」会**直接打开 Google Play**（不是手机自带的应用商店），没装 Play 的机器会提示改用镜像下载。
  - **装了但没选中**：直接给「去系统语音设置」，把首选引擎改成「Google 语音识别和语音合成」。
  - **已启用**：显示「已启用」，不再打扰。
- 镜像下的是 **合并好的完整单包**（不是分体 `.apks`）：小米 / MIUI 上**不用关闭「MIUI 优化」**，和普通 App 一样点安装即可。这个包用闲读自己的密钥重签过，所以装好之后**不要再用 Google 商店更新它**（会签名冲突），要换版本回到这张卡片重新下载。
- 引擎包同样支持**暂停 / 继续**。
- 这个引擎包要求 **Android 12L 及以上**（Google 官方限制），系统版本低会直接提示，不会白下 36 MB。
- 语音设置里的「重启」会真正重启 App，并回到语音设置页。

## 常见问题

- **翻译显示「稍后再试」**：翻译接口临时限流，过一会儿再点，不会自动反复重试。
- **没有声音**：检查系统语音引擎和媒体音量；换一个 TTS 引擎再试。
- **词性没标**：规则判断拿不准时会主动不标，避免误导；可以看单词卡里的全部释义。
- **新版本怎么更新**：在「我的 → 设置 → 软件更新与发布地址」里检查并直接下载，或到发布页下载新 APK 覆盖安装；不要卸载，卸载会清掉本地数据。
- **下载很慢**：镜像速度跟你所在的网络关系很大，App 每次下载前都会重新测速挑最快的几条。可以在「设置 → 下载镜像源」点一次同步，拉最新的可用清单；也可以换个网络（比如切到流量 / 换个 Wi-Fi）再试。
- **下载中断了**：点「继续」会从断点接着下，已下载的部分不会白费。为了避免中断，下载时尽量别切走或熄屏。
- **换签名会怎样**：安装包签名变了就不能覆盖安装，只能卸载重装，记得先导出存档。

## 隐私

不登录、不上传阅读记录，离线也能读；只有查词、翻译时才联网。
